# Стеклянные глубины

Учебная браузерная инди-игра о добыче стеклянных ваз в заброшенной шахте. Проект развивается 70 дней на **HTML, CSS и JavaScript**, без фреймворков и сборщика.

## Состояние: Day 9

Готов адаптивный стартовый экран с названием, иллюстрацией и разделом «Цель экспедиции». Кнопка «Начать экспедицию» открывает экран экспедиции и переносит фокус на его заголовок. На Day 9 поиск получает два исхода: с вероятностью 70% приносит одну вазу, иначе показывает сообщение «Поиск завершён: вазы не найдены. Попробуйте ещё раз.» без изменения счётчика. Шанс задан константой `VASE_FIND_CHANCE = 0.7` в `js/main.js`; отдельная попытка не гарантирует находку. Поиск по-прежнему занимает 300 мс: во время ожидания повторные нажатия игнорируются, а кнопка визуально приглушается и получает `aria-disabled="true"`, сохраняя фокус клавиатуры. Кнопка «Сбросить экспедицию» отменяет ожидающий результат, обнуляет счётчик и очищает сообщение без перезагрузки страницы. После сброса можно сразу искать вазы заново.

Счётчик попыток, индикатор прогресса, инвентарь, торговля, сохранение и другие механики ещё не реализованы. Дни 10–70 существуют только как план в [ROADMAP.md](ROADMAP.md).

## Запуск

Откройте `index.html` в браузере. На текущем этапе установка программ, пакетов и запуск сервера не нужны. Все ресурсы находятся в проекте; подключение к интернету для просмотра не требуется.

Нажмите «Начать экспедицию» мышью или перейдите к кнопке клавишей `Tab` и нажмите `Enter` либо `Пробел`. После перехода фокус с видимой рамкой окажется на заголовке «Экспедиция». Нажмите «Искать вазу» и дождитесь результата через 300 мс: находка увеличит счётчик на один, пустой поиск покажет сообщение без прибавления ваз. Повторные нажатия во время ожидания не запускают новый поиск. Кнопка «Сбросить экспедицию» отменяет незавершённый поиск и очищает текущие находки и сообщение, оставляя экран экспедиции открытым. Для управления клавиатурой переходите между кнопками через `Tab` и `Shift+Tab`, затем используйте `Enter` или `Пробел`. Перезагрузка страницы возвращает стартовый экран, обнуляет счётчик и очищает сообщение.

## Репозиторий и первый коммит

Исходники: [zaydu7in/glass-depths](https://github.com/zaydu7in/glass-depths), ветка `main`.

Первый коммит: `day-01: create project skeleton and static intro`. Он содержит только работу Day 1. Повторно создавать этот коммит не нужно.

В подготовленной рабочей папке Git уже инициализирован. Проверить историю и адрес репозитория:

```bash
git status
git log -1 --oneline
git remote -v
```

ZIP содержит исходники без скрытой истории Git. Чтобы получить файлы и историю коммитов на другом компьютере, клонируйте репозиторий:

```bash
git clone https://github.com/zaydu7in/glass-depths.git
cd glass-depths
```

В уже подготовленной рабочей папке повторное клонирование не требуется. Все Git-команды запускайте **из папки `glass-depths`**.

Автор первого коммита — `zaydu7in`; используется GitHub noreply-адрес. На другом компьютере перед следующими коммитами настройте автора только для этого репозитория:

```bash
git config user.name "zaydu7in"
git config user.email "345125836+zaydu7in@users.noreply.github.com"
```

Для `git push` нужна авторизация в GitHub. Публикация сайта через GitHub Pages не требуется для хранения проекта на GitHub и сейчас не настраивается.

## Ежедневный порядок

1. Откройте только текущий день в ROADMAP.
2. Выполните его небольшую задачу, затем проверьте указанный результат в браузере.
3. Просмотрите `git diff` и создайте осмысленный коммит с сообщением из плана.
4. Отправьте коммит через `git push` в тот же день и проверьте его на GitHub.

Минимум один содержательный коммит в каждый фактический день работы. Не создавайте пустые коммиты, не меняйте даты и не выполняйте будущие дни заранее. Номер Day обозначает день учебного проекта; календарные даты начнутся с вашего первого дня. Все 70 коммитов не создаются за один раз.
