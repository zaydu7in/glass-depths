# Стеклянные глубины

Учебная браузерная инди-игра о добыче стеклянных ваз в заброшенной шахте. Проект развивается 70 дней на **HTML, CSS и JavaScript**, без фреймворков и сборщика.

## Состояние: Day 1

Подготовлен только статический стартовый экран: название, описание идеи и небольшая иллюстрация вазы. Подключены отдельные CSS- и JavaScript-файлы. В JavaScript пока нет игровой логики.

Добыча, счётчики, инвентарь, торговля, сохранение и другие механики ещё не реализованы. Дни 2–70 существуют только как план в [ROADMAP.md](ROADMAP.md).

## Запуск

Откройте `index.html` в браузере. На Day 1 установка программ, пакетов и запуск сервера не нужны. Все ресурсы находятся в проекте; подключение к интернету для просмотра не требуется.

В подготовленной рабочей папке Git уже инициализирован. Проверить историю и адрес репозитория:

В уже подготовленной рабочей папке повторное клонирование не требуется. Все Git-команды запускайте **из папки `glass-depths`**.

## Ежедневный порядок

1. Откройте только текущий день в ROADMAP.
2. Выполните его небольшую задачу, затем проверьте указанный результат в браузере.
3. Просмотрите `git diff` и создайте осмысленный коммит с сообщением из плана.
4. Отправьте коммит через `git push` в тот же день и проверьте его на GitHub.

Минимум один содержательный коммит в каждый фактический день работы. Не создавайте пустые коммиты, не меняйте даты и не выполняйте будущие дни заранее. Номер Day обозначает день учебного проекта; календарные даты начнутся с вашего первого дня. Все 70 коммитов не создаются за один раз.
